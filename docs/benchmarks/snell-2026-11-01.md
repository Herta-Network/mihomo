# Snell packet batch performance

Compared `93ceeef5` (scalar packet sends) with `a58b9b23` (counted batches).

Host: Apple M5, macOS arm64, Go 1.27.3, `GOMAXPROCS=2`. Each case ran for one second per sample, five independent process samples per revision, with before/after order alternated. Values below are medians. Each operation sends four queued UDP payloads over a real loopback TCP connection through the outbound, reference, deadline and traffic wrappers; the Go inbound drains every packet. V6 uses its default shaped mode. Throughput counts plaintext payload bytes.

These historical samples used a new random test PSK in each process. V6 derives
its shaping profile from that key, so its before/after processes did not run an
identical workload. The v6 changes below are observations, not controlled
evidence of a batching speedup. The [owned downstream report](owned-downlink-2026-11-01.md)
uses a fixed test PSK in both revisions to correct this measurement issue.

Allocated bytes are allocation traffic, not retained heap. They include both local endpoints and framing/traffic wrappers. The v3/v4 batch paths were faster in this workload but allocated more per packet, especially v3, whose framing at that revision copied payloads before AEAD encoding.

Independent test-process peak RSS, collected with macOS `/usr/bin/time -l` after compilation:

| Revision | Median peak RSS | Sample range |
| --- | ---: | ---: |
| before | 48.73 MiB | 44.58–55.00 MiB |

RSS ranges overlap. These results do not establish lower production memory use, isolated-packet latency, high-concurrency memory use, or WAN throughput. The benchmark exercises a sustained four-packet queue, not a guarantee that normal traffic will always form a batch.

Reproduce by copying `listener/inbound/snell_benchmark_test.go` into detached worktrees at the two revisions, building each with `go test -c ./listener/inbound`, then alternating:

The current fixture fixes the PSK. Using it is a controlled rerun rather than a
literal replay of the historical random-profile v6 timings above.

```sh
GOMAXPROCS=2 /usr/bin/time -l ./inbound.test \
  -test.run '^$' -test.bench '^BenchmarkSnellPacketWrite$' \
  -test.benchtime=1s -test.count=1
```

The timer includes draining the receiver. Each run checks exact packet count and plaintext upload accounting. Raw numeric samples are in `snell-2026-11-01.json`.
